# Rolly Polly

Rolly Polly — браузерная игра на React, где игрок набирает очки бросками набора кубиков и между раундами улучшает свой пул. Проект переносит механику бонусов, стритов, специальных кубиков и стикеров в интерфейс на Vite + TypeScript.

## ✨ Особенности
- Запускает пошаговую dice-game механику прямо в браузере.
- Поддерживает раунды, лимит бросков и растущую цель по очкам.
- Показывает активные бонусы, штрафы и итоговый счёт.
- Разрешает улучшать кубики или добавлять стикеры между раундами.
- Поддерживает управление клавишей `Space` через `mousetrap`.

## 🚀 Быстрый старт
### Установка зависимостей
```bash
npm install
```

### Запуск в разработке
```bash
npm run dev
```

### Сборка
```bash
npm run build
```

### Предпросмотр production-сборки
```bash
npm run preview
```

## 📁 Структура проекта
- `src/App.tsx` — основной интерфейс игры и управление раундами.
- `src/game.ts` — правила подсчёта очков, бонусов и стикеров.
- `src/die.ts` — типы кубиков и логика бросков/апгрейдов.
- `src/sticker.ts` — описание добавочных и множительных стикеров.
- `src/game.test.ts` — тесты игровой логики.
- `public` — статические ресурсы приложения.

## 🛠 Использование
### Игровой процесс
После запуска откройте приложение в браузере и бросайте кубики кнопкой `Roll Die` или клавишей `Space`.

### Что можно делать между раундами
- добавить случайный кубик;
- улучшить случайный кубик;
- добавить случайные стикеры на один из кубиков.

### Подсчёт очков
Игра показывает сумму числовых значений, бонусы за пары/тройки/квады/стриты, эффекты максимальных и минимальных бросков, а затем применяет добавочные и множительные стикеры.
